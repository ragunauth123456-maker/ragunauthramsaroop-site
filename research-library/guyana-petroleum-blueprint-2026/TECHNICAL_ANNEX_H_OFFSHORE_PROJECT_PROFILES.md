# TECHNICAL ANNEX H
## Guyana offshore project profiles, production controls and project-level evidence template

Purpose: organize each offshore project as a separate auditable case. Source IDs refer to SOURCE_REGISTER.md.

## H1. Why project-level analysis matters

The Stabroek Block is not one homogeneous project. Each development has its own:
- production licence;
- FPSO;
- wells;
- capacity;
- capital programme;
- EIA;
- permit conditions;
- startup;
- production;
- cost recovery;
- spill plan;
- decommissioning exposure.

Aggregating the entire block can hide differences.

## H10. Production measurement

Production data should distinguish:
- gross wellstream;
- stabilized crude;
- water;
- gas;
- reinjection;
- flare;
- fuel use;
- export.

Public dashboards often focus on crude output. Technical regulators need the full material balance.

## H11. Metering

Meter governance should cover:
- calibration;
- seals;
- redundancy;
- maintenance;
- data transmission;
- audit trail;
- correction procedure.

A government must be able to reproduce the entitlement calculation.

## H12. Downtime

For each project, record:
- planned maintenance;
- unplanned outage;
- equipment failure;
- weather;
- reservoir constraint.

Downtime affects annual output and revenue.

## H13. Capacity versus throughput

Nameplate capacity is an engineering design measure.

Actual throughput depends on:
- wells;
- reservoir;
- maintenance;
- debottlenecking;
- safety;
- weather.

A daily record above nameplate for a short period should not be extrapolated to annual production without evidence.

## H14. Reservoir performance

The state should receive sufficient data to monitor:
- pressure;
- water cut;
- gas-oil ratio;
- injection;
- decline.

Reservoir uncertainty affects future revenue.

## H15. Development cost

Each project should have a versioned cost estimate:
- sanction estimate;
- revised estimate;
- audited eligible cost;
- final cost where known.

Operator headline development cost and recoverable cost are not necessarily identical.

## H16. Cost attribution

Costs should be tagged to:
- project;
- shared infrastructure;
- exploration;
- appraisal;
- corporate overhead.

Shared costs require contractual allocation rules.

## H18. Incident taxonomy

Classify:
- safety;
- spill;
- flare;
- discharge;
- equipment failure;

Not every incident has equal consequence.

## H19. Production licence controls

Licence review should extract:
- term;
- area;
- development plan;
- reporting;
- measurement;
- safety;
- spill preparedness;
- abandonment;

The final text should quote sparingly and cite the original.

## H21. Government-lift template

For each project/month:
- government entitlement barrels;
- cargo date;
- realized price;
- sale value;
- settlement;
- NRF deposit.

This connects operational and financial records.

## H22. Cumulative Stabroek analysis

After building project profiles, aggregate only compatible measures:
- actual barrels;
- government lifts;
- cost recovery;
- fund receipts.

Maintain project detail underneath.

## H23. Project closeout

Eventually each project needs:
- cessation plan;
- well abandonment;
- facility removal;
- environmental monitoring;
- decommissioning cost;
- security;
- residual liability.

Start tracking before decline.

## H24. New-producer project template

A new country should adopt the project record before sanction.

Mandatory folders:
1. legal;
2. reservoir;
3. economics;
4. environment;
5. safety;
6. metering;
7. fiscal;
8. local content;
9. emergency;
10. closure.

## H25. Evidence maturity labels

Use:
- observed;
- audited;
- regulator-approved;
- operator-reported;
- government-reported;
- forecast;
- disputed;
- pending.

This prevents mixed evidence.

## H26. Annex conclusion

Project-level evidence is the bridge between national petroleum headlines and actual regulatory performance. Guyana's multi-FPSO expansion makes the project record essential for understanding production, costs, environmental conditions and public revenue.
