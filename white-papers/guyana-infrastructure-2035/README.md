# Guyana Infrastructure 2035

Independent thought leadership project prepared in September 2026.

## Purpose

This project rebuilds the infrastructure-outlook concept around five questions:

1. What is the current scale of investment?
2. Which projects are operational, under construction, in procurement, or still in planning?
3. How do power, transport, water, housing, digital and social infrastructure depend on one another?
4. Where are the delivery-capacity constraints?
5. Which measurable outcomes should define success?

## Deliverables

- 39-slide 16:9 executive presentation
- publication-ready PDF
- web companion in this directory
- source register
- project-status dataset
- reproducible design system

The deck is original work. It uses KPMG Guyana's 14 September 2026 infrastructure outlook as a benchmark source and refreshes the analysis with primary public information available through 28 September 2026.

Typography: Inter Display for headlines and Inter for body copy.

The visual system favours wide editorial layouts, large quantitative callouts, restrained sector accents, short source tags, maturity views and outcome dashboards over dense report-style pages.

## Research convention

Official government project-status statements are treated as attributed status reporting. Forward-looking dates are reported targets, not guarantees. Figures are rounded for presentation. The latest dated source is used where public releases differ.

Data cut-off: 28 September 2026.
